## 清空聊天记录

页面 ID: `10976098481852560` · 链接: https://www.showdoc.com.cn/mrsanshui/10976098481852560

**简要描述：**

- 清空聊天记录

**请求URL：**

- `http://127.0.0.1:8989/api`

**请求方式：**

- POST

**JSON参数：**

| 参数名 | 是否必选 | 类型 | 说明 |
|:--- |:--- |:--- |:---  |
| type | 是 | int | 消息类型 |
| user_id | 是 | string | 用户ID/群ID |

**发送示例：**

```json
{
    "type": 10000,
    "user_id": "788xxx"
}
```

## 语音转文字

页面 ID: `10976100245381341` · 链接: https://www.showdoc.com.cn/mrsanshui/10976100245381341

**简要描述：**

- 语音转文字

**请求URL：**

- `http://127.0.0.1:8989/api`

**请求方式：**

- POST

**JSON参数：**

| 参数名 | 是否必选 | 类型 | 说明 |
|:--- |:--- |:--- |:---  |
| type | 是 | int | 消息类型 |
| msg_id | 是 | string | 消息ID(消息推送中获取) |

**发送示例：**

```json
{
    "type": 10003,
    "msg_id": "1000925"
}
```

**返回示例：**

```json
{
    "data": {
        "text": "你好啊。" //文字内容
    },
    "errmsg": "OK",
    "errno": 0
}
```

## 获取当前聊天窗口信息

页面 ID: `10976101378170898` · 链接: https://www.showdoc.com.cn/mrsanshui/10976101378170898

**简要描述：**

- 获取当前聊天窗口信息，可搭配《本地查询好友信息》或者《获取群信息》接口使用

**请求URL：**

- `http://127.0.0.1:8989/api`

**请求方式：**

- POST

**JSON参数：**

| 参数名 | 是否必选 | 类型 | 说明 |
|:--- |:--- |:--- |:---  |
| type | 是 | int | 消息类型 |

**发送示例：**

```json
{
    "type": 10005
}
```

**返回示例：**

```json
{
    "data": {
        "is_chat_room": 1, //是否是群聊
        "user_id": "R:1970326367001468" //聊天对象的微信ID、群ID、公众号ID等
    },
    "errmsg": "OK",
    "errno": 0
}
```
