## 开启/关闭自动更新

页面 ID: `10976093323560181` · 链接: https://www.showdoc.com.cn/mrsanshui/10976093323560181

**简要描述：**

- 开启/关闭自动更新

**请求URL：**

- `http://127.0.0.1:8989/api`

**请求方式：**

- POST

**JSON参数：**

| 参数名 | 是否必选 | 类型 | 说明 |
|:--- |:--- |:--- |:---  |
| type | 是 | int | 消息类型 |
| state | 是 | int | 0:关闭 1:开启 |

**发送示例：**

```json
{
    "type": 7000,
    "state": 0
}
```
